## 2026-02-20（方向为负分类修复）

### A. 重验阶段的价差定义（统一口径）

- `tradable_spread = (short_sell - long_buy) / long_buy`
- `entry_spread_metric = log(short_sell / long_buy)`

解释：
- `tradable_spread > 0` 才代表该方向具备“先开仓即可成交的正价差”。
- `tradable_spread <= 0` 代表方向为负（买贵卖便宜），必须归类为 `no_tradable_direction`，不应算作 `entry_spread_too_small`。

### B. 重验分类标签优先级（本次修复后）

Type B/Type C 统一优先级：
1. `no_tradable_direction`
2. `entry_spread_too_small`
3. `below_threshold_after_reval`

具体规则：
- 先判方向：若 `tradable_spread <= 0` -> `no_tradable_direction`。
- 仅当 `tp_needed > 0` 且 `entry_spread_metric < tp_needed` 时，才判 `entry_spread_too_small`。
- 其余未通过阈值（`pnl_hat_eval` / `win_prob_eval`）的情况，归为 `below_threshold_after_reval`。

### C. 本次代码修复点

- 文件：`trading/live_trading_manager.py`
- 函数：`_revalidate_with_orderbook_type_c(...)`
- 修复前问题：Type C 在 `not ok` 分支里未优先判断 `tradable_spread<=0`，且 `entry_spread_too_small` 未限制 `tp_needed>0`，导致方向为负的样本被误标为 `entry_spread_too_small`。
- 修复后：
  - 优先将 `tradable_spread<=0` 标记为 `no_tradable_direction`；
  - `entry_spread_too_small` 增加 `tp_needed>0` 条件；
